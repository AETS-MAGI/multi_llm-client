# 2026-03-24 Rust bench compare (baseline vs side)

## Scope

Added direct baseline-vs-side comparison command on top of phase summary outputs.

## New CLI

- `--bench-compare <baseline_phase_summary.tsv>`
- `--compare-side <side_phase_summary.tsv>`
- `--compare-out <path>` (optional)

## Input

- Baseline/side files are expected to be generated by:
  - `<out>_phase_summary.tsv` from built-in bench runs.

## Output

- Default output: `<baseline>_vs_<side>.tsv`
- Grouping key:
  - `mode`, `num_thread`, `keep_alive`, `max_tokens`, `phase_signature`
- Metrics compared:
  - baseline/side rows and ok_rows
  - baseline/side averages for `ttft`, `total`, `tok_s`
  - baseline/side averages for `decode_tok_s_proxy`, `prefill_decode_ratio`
  - delta and ratio columns for each major metric

## Validation

```bash
cargo check
cargo run -- --bench predict-sweep --preset gfx900_anchor_side1024 --predict-values 64 --repeat 1 --prompt "short test" --quiet --out worklog/bench_predict_side_smoke.tsv
cargo run -- --bench-compare worklog/bench_predict_phaseagg_smoke_phase_summary.tsv --compare-side worklog/bench_predict_side_smoke_phase_summary.tsv --compare-out worklog/bench_predict_baseline_vs_side.tsv
```

## Observed

- `worklog/bench_predict_baseline_vs_side.tsv` generated successfully.
- Example row showed matched key and meaningful deltas (TTFT/total increase on side1024; tok/s slightly lower).
